## Descrição

<p align="center">
  <img src="/street hoops logo.jpg" alt="Street Hoops" width="600">
</p>

Este projeto consiste no desenvolvimento de uma **solução digital** para conectar pessoas e lugares para a prática de esportes amadores.

A proposta envolve a criação de um ecossistema composto por:

- 📱 **Aplicativo Mobile (Usuário)**
- 🔗 **Backend (API) e Banco de Dados**

O sistema permite que usuários criem ou participem de partidas, filtrando por esporte, local, horário e distância, além de consultar locais disponíveis para prática esportiva na região.

A solução busca resolver a dificuldade comum de encontrar parceiros de jogo e locais disponíveis de forma organizada, centralizando essa busca em uma única plataforma.
